# MOONMART — Starter Game & Art Pack v0.1

A Godot 4 **prototype** for a cozy supernatural mystery shopkeeping game.

## What is included
- Runnable Godot 4 scene with WASD movement, animated player walk, independently wandering customers, interaction hotspots, small shop economy, a shift clock, quest flags and local save/load.
- Individual transparent PNG sprites and editable SVG sources for scenery, furniture, characters and effects.
- Original visual reference and generated gameplay concept images in `references/`.
- Narrative bible, character arcs, first-five-nights script outline, dialogue samples, content schemas and prioritized development tickets.
- A small asset catalog and production notes.

## Run
1. Install **Godot 4.2 or later**.
2. Import `project.godot` in Godot Project Manager.
3. Press **F6** in the scene editor or **F5** to run the project.
4. Use **WASD / arrow keys** to move, **E** to interact, **Enter/Esc** to dismiss dialogue, and **F5** during play to save.

## Important limitations
This is a functional *starter prototype*, not a polished game or finished production art. The SVG/PNG pieces are simplified original recreations in the reference palette; they are **not clean separations from the concept painting**. Character movement uses a lightweight sprite-frame approximation. Customers wander but do not yet use full navigation/queues. Dialogue and quest state are proof-of-concept. UI uses Godot's fallback font; the illustrated lettering is a **style reference**, not an embedded licensed typeface. No real dynamic lighting or full decoration editor yet.

## Art direction
Use `references/original_style_reference.png` as the ultimate art style authority, and `references/gameplay_reference.png` for composition. Soft painterly textures, deep lavender/indigo shadows, peach lighting, warm cream typography, rounded shapes, subtle supernatural effects. **No pixel art.**

## Project codename and title
The official working title is **Moonmart**. Previous working title is retired.
