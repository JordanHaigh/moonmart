# Moonmart radio loops

These three original 32-second stereo loops are generated by `tools/build_moonmart_radio.ps1`. The script uses deterministic .NET synthesis only; no recordings, third-party samples, or external libraries are used. Each arrangement combines soft sustained chord tones with a light melodic pluck, and two tracks add a restrained brushed-noise accent. The tones are musical approximations, not sampled acoustic instruments.

| Station | File | Arrangement |
|---|---|---|
| Window Seat | `window_seat.wav` | Airy sustained chords with a sparse, soft music-box motif |
| Bellwether After Hours | `bellwether_after_hours.wav` | Warm piano-like tones, plucked-string notes, and a faint brushed texture |
| Harbour Hush | `harbour_hush.wav` | Airier sustained chords and a slower high-register melody |

All files are 44.1 kHz, 16-bit stereo PCM and share a fixed 32-second loop length. Generated peaks are −9.5 dBFS, leaving headroom for the independent Music bus level. Set `AudioStreamWAV.loop_mode` to forward looping in Godot; these plain PCM WAV files do not include application-specific loop metadata.

`radio_metadata.json` records the generated titles, relative paths, arrangement notes, duration, sample format, peak, and file sizes. Rebuild from the repository root with:

```powershell
& tools/build_moonmart_radio.ps1
```

The script rewrites only this directory's three generated WAVs and metadata file.
