# Moonmart original starter — preservation area

This directory holds the restored sprite-based original Godot starter script, scene and project settings. It is **not** yet a full copy of the original 75-file starter archive.

The original starter also contains 28 PNG sprites, 28 SVG sources, a contact sheet, 4 concept references, docs, data and other files. Those binary assets have not been committed here. The script expects images under `starter_original/assets/png/` and will not run correctly until those files are imported.

The main repository's root `project.godot` remains the simpler procedural prototype; no existing code was overwritten.

To launch the original starter after importing its assets, open `starter_original/project.godot` in Godot 4.2+. Do not mistake this preservation area for a tested build.

See `docs/PRODUCTION_STATUS.md` for project status.
