# Legacy art prototypes

The SVG illustrations and earlier audio placeholder in this directory are retained as historical prototypes. They are not the production art pack and are not referenced by the current runtime scenes. Do not use them for new production work.

The authoritative game artwork is the high-resolution raster pack in [`raster/`](raster/README.md), produced against `../art_import/` and governed by Sections 27 and 28 of [`Moonmart.md`](../Moonmart.md). Keep environment plates intact; dynamic light, weather, particles, and story effects belong on independent layers. Do not add SVG placeholder artwork to the runtime.
