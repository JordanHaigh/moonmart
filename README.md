# Moonmart

Cozy supernatural mystery shopkeeping game, built in Godot 4.

## Project direction

- 2D side-on exploration with shallow depth movement
- Hand-painted storybook environments inspired by the original Moonmart reference art
- Warm lavender, navy, peach and cream palette
- Shopkeeping, customer relationships, supernatural mysteries and expandable rooms
- Heartwarming, bittersweet storytelling set in Bellwether

## Development status

Pre-production / starter prototype. The complete local prototype and visual assets are being prepared for import; this repository currently contains project documentation only.

## Core cast

Miso (orange shop cat), Pip (friendly ghost), Agnes Thorne, Fern, Lucien Vale, Wren Hollow and the Conductor.

## Narrative

Six chapters covering Moonmart, the Between, the Long Midnight and the Midnight Train. The player manages a shop that serves as a sanctuary between worlds.
