# Dialogue localization

`data/dialogue/story.json` is the source-language narrative catalog. Runtime selects the system language returned by Godot and looks for optional `data/locales/<language>/dialogue.json` and `data/locales/<language>/ui.json` overlays. For example, a future French catalog would live at `data/locales/fr/dialogue.json` and `data/locales/fr/ui.json`.

Keep the source catalog's stable story, conversation, character, and route IDs. Include only translated values; missing keys fall back to English. Nested objects merge by key. Arrays replace the source array, so translate every line in a conversation together and preserve its line order. Keep format placeholders such as `%s` in the same order and count as the English source.

The UI catalog has a top-level `strings` object keyed by stable interface IDs, for example `{ "schema_version": 1, "strings": { "settings.close": "Close" } }`. Keep format placeholders in the same order and count as the English source. Empty or non-string UI values are ignored.

The English source remains playable when no catalog exists, when a key is missing, or when an entry is invalid. `data/locales/en/ui.json` is the source-key catalog for settings and every remappable control label, including controller button positions, stick axes, and trigger axes, interaction prompts, pause and journal panels, save recovery, welcome/HUD hints, mystery-board guidance, investigation cases and hypotheses, clue descriptions, seven environmental puzzles, the town map and seasonal calendar, generated journal sections and titles, saved ending memories, open promise text, story event titles, ledger, housekeeping, companion care, radio, upgrades, shift status, pause actions, decoration controls and results, checkout, inventory and stock notices, stock/backroom instructions, system-generated shift and interaction messages, all 83 optional event notices, recipe preparation and experimentation, seasonal stock markers, and product/recipe display names including furniture names in the decoration data. `data/locales/es/ui.json` translates all 1,441 English UI keys, including named placeholders and localized accepted puzzle answers. The investigation board's case titles, theories, result responses, clue text, and guided clue hints use stable content IDs while leaving gameplay data in English. `data/locales/es/dialogue.json` translates all 37 story-event summaries, all 25 everyday visitor lines, the `%s` fallback line, and all 87 character conversations plus paired visitor banter. Each character conversation retains its source ID, two-line count, line order, and placeholders; paired exchanges preserve participant IDs and alternating speaker order. Role labels such as `The Conductor` are translated for display. Routing metadata remains source-authoritative. The current English and Spanish catalogs cover the audited runtime keys; in-game fit/readability review and additional non-English catalogs remain open. These overlays preserve English fallback without duplicating quest logic or changing save IDs.
